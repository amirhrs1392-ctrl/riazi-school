سامانه ریاضی مدرسه امام رضا واحد ۳ — نسخه یکپارچه

این بسته دو بخش دارد:
1) فایل‌های عمومی وب‌سایت برای GitHub Pages
2) کد تابع امن دستیار هوشمند برای Supabase Edge Functions

تغییرات رابط کاربری
- داشبورد دسته‌بندی‌شده ویژه معلم برای کلاس‌های ۷۰۳ و ۷۰۴
- دسترسی سریع به گزارش‌ها، تکالیف، امتیازها، گفتگوها و دستیار
- دسته‌بندی گزارش‌ها بر اساس نقش نویسنده: سرگروه کل / سرگروه
- دسته‌بندی پیام‌ها بر اساس نقش فرستنده: سرگروه کل / سرگروه / پشتیبان
- دستیار یکپارچه در پنل همه نقش‌ها، با ورودی گفتار فارسی و خواندن صوتی در مرورگرهای سازگار
- پیش‌نمایش و تأیید صریح برای هر عملیات تغییردهنده داده
- نام‌گذاری نقش‌ها فقط با عنوان‌های رسمی: معلم، سرگروه کل، سرگروه، پشتیبان

وظایف دستیار
- پاسخ‌گویی و آموزش مرحله‌به‌مرحله ریاضی هفتم
- ساخت تمرین و آزمون پیشنهادی
- مشاهده تکالیف در محدوده دسترسی حساب
- مشاهده و خلاصه‌سازی گزارش‌های قابل‌مشاهده
- مشاهده امتیازها و رتبه‌بندی در محدوده دسترسی
- مشاهده اعضای گروه در محدوده دسترسی
- تهیه پیش‌نویس تکلیف جدید (فقط معلم)
- تهیه پیش‌نویس گزارش کار متنی (فقط سرگروه و فقط گروه خودش)
- تهیه پیش‌نویس امتیاز مثبت (معلم یا سرگروه کل؛ سرگروه کل فقط کلاس خودش)
- هیچ عملیات نوشتنی بدون کلیک روی «تأیید و ثبت» اجرا نمی‌شود.

راه‌اندازی بخش هوش مصنوعی (یک‌بار برای همیشه)
1) وارد Supabase Dashboard همان پروژه اصلی سامانه شو؛ پروژه با آدرس dtqgjodpdioatzlnibmw.supabase.co شناخته می‌شود.
2) از بخش Edge Functions یک تابع با نام دقیق site-assistant بساز.
3) محتوای فایل supabase/functions/site-assistant/index.ts را در فایل index.ts تابع قرار بده و Deploy کن.
4) در تنظیمات Secrets مربوط به Edge Functions یک Secret با نام OPENAI_API_KEY اضافه کن و کلید API را فقط همان‌جا قرار بده.
5) در صورت نیاز، Secret با نام OPENAI_MODEL را برابر gpt-6-luna تنظیم کن؛ در صورت نبودن این Secret، همین مدل به‌صورت پیش‌فرض استفاده می‌شود.
6) تنظیمات تابع در supabase/config.toml مقدار verify_jwt=true را فعال می‌کند؛ تابع فقط با نشست کاربر واردشده کار می‌کند.

نکات امنیتی مهم
- کلید OPENAI_API_KEY را هرگز داخل index.html، فایل ZIP عمومی، GitHub یا پیام چت قرار نده.
- هیچ service_role key در این بسته وجود ندارد و لازم نیست ایجاد یا منتشر شود.
- عملیات Edge Function با JWT همان کاربر و سیاست‌های Row Level Security پایگاه داده انجام می‌شود.
- برای ثبت واقعی عملیات، نقش کاربر و کلاس او دوباره در سرور بررسی می‌شود.
- استفاده از API هوش مصنوعی ممکن است هزینه داشته باشد؛ کلید و سقف مصرف را مسئول بزرگسال/مدرسه در حساب API تنظیم کند.
- این بسته هیچ SQL migration را اجرا نمی‌کند و هیچ جدول، حساب، تکلیف، گزارش، پیام یا امتیاز قبلی را پاک یا جابه‌جا نمی‌کند.
- پروژه و داده‌های مستقل سایت دوم به پروژه اصلی منتقل نشده‌اند؛ فقط الگوی دسته‌بندی و ساختار کاری معلم از روی کد آن بازطراحی شده است.
